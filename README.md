# nmeagc

## NMEA GNSS data client and visualizer

This is a NMEA GNSS messages client with a Terminal User Interface for easy visualization. It is implemented in Rust as a [Ratatui] app based on its [event driven template].

[Ratatui]: https://ratatui.rs
[event driven template]: https://github.com/ratatui/templates/tree/main/event-driven
